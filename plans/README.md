**RELEASE POLICY (maintainer directive, 2026-07-12)**: the next release is ONE
coordinated breaking upgrade — `0.6.0` (pre-1.0, so the 0.x minor is the
breaking slot; changesets for breaking changes use `minor`). Backward
compatibility is NOT required anywhere in this plan set: no deprecation
cycles, no compat overloads/shims, no parallel v2 methods. Remove replaced
surface outright; the deliverable owed to users is a MIGRATION GUIDE (one
follow-up plan should own writing it before the 0.6 publish). One deliberate
exception: URL wire-format READ compatibility (accepting old `c:` payloads)
is kept — shared/bookmarked URLs in the wild aren't API consumers, and the
fallback parse is near-zero cost. Plans written before this directive
contained softer language (deprecate-and-alias, parallel methods); where
found, it has been edited — if an executor encounters residual compat
language, this policy wins.

## Findings audited but not planned this round

Correctness/quality — worth doing, lower leverage than the planned set:

- **CORE-02** Percentage formatter guesses decimal-vs-percent (`packages/core/src/lib/format-utils.ts:112-122`, `value > 1` heuristic) — wrong display for sub-1% values; needs an explicit config flag. S effort.
- **CORE-03** Dynamic row measurement leaves downstream offsets stale (`virtualization-manager.ts:485-495` recalculates only one row) — overlapping rows in dynamicRowHeight mode. M.
- **CORE-04** Date formatter appends a timezone label without converting and ignores configured locale (`lib/date-utils.ts:42-51`). M.
- **CORE-06** URL compression `renameKeys` recurses into user data; keys named `c/t/o/v/n/m/d` in filter meta/values get mangled on restore (`utils/compression.ts:56-72`). Fix together with 006's wire-format version bump (`c2:` prefix).
- **CORE-07** `updateState` emits several `state_changed` events per bulk update → refetch waterfall on URL hydration (`table-state-manager.ts:234-249`, `:522-577`). M; batching flag.
- **CORE-08** Six managers duplicate subscribe/notify with drifted error policy (silent swallow in `table-state-manager.ts:616-624` vs. `console.error` in `filter-manager.ts:489-498`). Extract an emitter base. M.
- **CORE-09** Virtualization offset math is O(n) per lookup (`virtualization-manager.ts:464-514`) — degrades past tens of thousands of rows; prefix-sum/Fenwick cache. L; needs 010's harness for regression tests first.
- **CORE-10** `includeNull`/`supportsNull` are dead in validation (`filter-manager.ts:360-441`) — null-only filters can't pass strict mode. Needs a semantics decision; fold into 006.
- **ADAPTER-03** Manual-join data queries paginate over row-multiplied results on one-to-many joins (flat `leftJoin` + `limit`, e.g. `postgres-query-builder.ts:503-539`; always on MySQL/SQLite) — pages under-fill even after 003 fixes `total`. L; needs distinct-PK subquery or relational routing. The biggest unplanned correctness item — plan it when 007 stabilizes the query-builder layer.
- **ADAPTER-05** Primary-table resolver `break`s on first relationship match and falls back to first table silently (`primary-table-resolver.ts:156-164`, `:222-225`); FK name-guessing can bind wrong columns (`relationship-detector.ts:1072-1088`). M; prefer explicit-config errors.
- **ADAPTER-06** Faceted values / min-max ignore active filters and inflate under joins (`drizzle-adapter.ts:744-788`). M; adapter contract may need widening — fold into 006/post-006.
- **ADAPTER-07** (partially covered by 004) Adapter-side silent filter drops on type mismatch (`filter-handler.ts:733-741`, per-operator `return undefined`) — fail-open. Ride along with 007's router extraction.
- **UI-05/06/08** Render-perf: unmemoized rows/cells in `table.tsx:788-887`; `VirtualizedTable` recreates per-row ResizeObservers every render (`virtualized-table.tsx:96-112`, `:196`); auto-show effect + six callback-bridge effects churn (`table.tsx:301-375`). M each; need 010's harness for safe memoization.
- **DX-10** Enable `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes` — right for a type-safety-flagship library; blast radius unknown without a compile. Investigate after 005.
