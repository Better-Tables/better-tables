`0.6.0` (pre-1.0: the 0.x minor is the breaking slot; breaking changesets use

before the 0.6 publish. One exception: URL wire-format READ compatibility (old

plan text still contains softer compat language, this policy wins.

else is done; Drizzle abstraction/provider-readiness proceeds.
