`drizzle-orm` and your driver (`better-sqlite3`, `postgres`, `mysql2`) are peer dependencies — install the ones you use.

## Capabilities

- Schema, driver, and relationship auto-detection from your Drizzle instance
- Automatic JOINs from relationship dot-paths (`customer.company`), including array foreign keys
- Filters (full operator set incl. AND/OR trees), sorting, pagination, global counts
- Facets: `getFacetedValues` / `getMinMaxValues` with self-exclusion
- Schema introspection (`describeColumns`) for [auto columns](/docs/columns/auto-columns)
- Cell writes via `updateRecord` + `resolveCellWriteTarget` for [inline editing](/docs/inline-editing)
- Tuning: query caching, join budget, large-IN batching, query logging, timing warnings

Full guide with every factory option: [Drizzle adapter](/docs/adapters/drizzle).
