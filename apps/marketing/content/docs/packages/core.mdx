## Exports by area

| Area | Exports |
|---|---|
| Factory | `betterTables`, `defineTable` — the flagship entry points ([Quick Start](/docs/quick-start)) |
| Path builders | The `t` callback surface: `t.text` / `t.number` / `t.date` / `t.option` / `t.multiOption` / `t.boolean` / `t.computed` / `t.custom` / `t.auto` ([Columns](/docs/columns)) |
| Column resolution | `resolveTableColumns` — auto-column resolution at mount ([Auto columns](/docs/columns/auto-columns)) |
| Editing | `cellEditAction` on the factory, `ValidationRule`, `EditableConfig` ([Inline editing](/docs/inline-editing)) |
| Managers | `TableStateManager`, `FilterManager`, `PaginationManager`, `SortingManager`, `SelectionManager`, `VirtualizationManager` |
| Stores & URL | `getTableStore`, `UrlSyncAdapter`, `UrlSyncConfig`, `serializeFiltersToURL` / `deserializeFiltersFromURL`, `serializeTableStateToUrl` / `deserializeTableStateFromUrl` ([URL State](/docs/url-state)) |
| HTTP transport | `httpAdapter`, `createAdapterRouteHandler` ([HTTP adapter](/docs/adapters/http)) |
| Adapter contract | `TableAdapter`, `FetchDataParams`, `FetchDataResult`, `FacetQueryParams`, `AdapterFeatures`, `InferredColumnSpec` ([Custom adapters](/docs/adapters/custom)) |
| Memory adapter | `memoryAdapter(rows, options?)` — the full pipeline over an in-memory array ([Custom adapters](/docs/adapters/custom#memory-adapter)) |
| Standalone columns | `defineTableRow`, `defineColumns`, and the builder classes (`TextColumnBuilder`, …) for hand-built columns ([Columns](/docs/columns#standalone-columns-no-schema)) |
| Filter types | `FilterState`, `FilterGroupNode`, `FilterOperator` + per-type operator unions, `FilterConfig` ([Filtering](/docs/filtering)) |
