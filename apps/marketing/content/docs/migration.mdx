---
title: Migration
description: Move from 0.5 createColumnBuilder / defineColumns to betterTables + defineTable.
---

Better Tables 0.6 makes `betterTables()` + `defineTable()` + path builders the flagship API. Legacy `createColumnBuilder` / `defineColumns` still compile but are deprecated.

## Before → after

```ts
// 0.5 (legacy)
const cb = createColumnBuilder<Row>();
const columns = defineColumns([
  cb.text().id('subject').filterable().build(),
]);
```

```ts
// 0.6 (flagship)
export const tables = betterTables({ database: drizzleAdapter(db) });

export const ticketsTable = defineTable<typeof tables>()('tickets', (t) => ({
  columns: [t.text('subject').filterable()],
}));
```

## Checklist

1. Introduce `betterTables({ database })` once per app/module
2. Replace column factories with `defineTable` / `tables.define`
3. Switch fetches to `tables.fetchData(table, params)`
4. Pass `table.columns` (or `table={def}`) into UI
5. For edits, prefer `tables.cellEditAction` over ad-hoc routes

Full runbook: repository root [`MIGRATION.md`](https://github.com/Better-Tables/better-tables/blob/main/MIGRATION.md).
