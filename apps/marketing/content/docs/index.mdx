Better Tables is a TypeScript monorepo for building production data tables: define columns once with the flagship API, let an adapter turn that into SQL, and render with React components you own.

<Callout type="info" title="API version">
This handbook documents the 0.6 flagship API (`betterTables()` / `defineTable()` / path builders) exclusively. The legacy `createColumnBuilder` / `defineColumns` API still compiles but is deprecated — see [Migration](/docs/migration) when upgrading older code.
</Callout>

## Packages

| Package | Role | Distribution |
|---|---|---|
| `@better-tables/core` | Column builders, managers, adapter contracts | npm |
| `@better-tables/adapters-drizzle` | Drizzle query generation (Postgres / MySQL / SQLite) | npm |
| `@better-tables/ui` | React table & filter components | CLI copy (private) |
| `@better-tables/cli` | `better-tables init` — copies UI into your app | npm |

**Data flow:** `defineTable()` column definitions → adapter executes queries → UI renders and manages client state, optionally synced to the URL.

```ts
import { betterTables, defineTable } from '@better-tables/core';
import { drizzleAdapter } from '@better-tables/adapters-drizzle';

export const tables = betterTables({
  database: drizzleAdapter(db),
  defaults: { pageSize: 20 },
});

export const ticketsTable = defineTable<typeof tables>()('tickets', (t) => ({
  columns: [
    t.text('subject').searchable().filterable().sortable(),
    t.option('status').options([{ value: 'open', label: 'Open' }]).filterable(),
  ],
}));

const result = await tables.fetchData(ticketsTable, {
  pagination: { page: 1, limit: 20 },
});
```
